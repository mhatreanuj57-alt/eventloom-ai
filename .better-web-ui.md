## Design Context

### Users
People organizing weddings, birthdays, and community gatherings; they need practical budgets, preparation timelines, vendor checklists, and creative ideas. This audience and use case come from the owner's challenge statement.

### Brand Personality
Premium, warm, clear. Calm planning with a celebratory editorial touch. The owner requested a stunning premium UI, responsive behavior, and both themes; the warm editorial interpretation is a stated working assumption.

### Aesthetic Direction
Ivory and ink with muted olive and orange accents, DM Sans for interface text and Instrument Serif for expressive headings. Real event photography with restrained crops, generous spacing, hairline borders, and subtle transitions. Dark theme uses warm charcoal surfaces. Avoid fake testimonials and invented success metrics.

### Implementation Defaults
Explicit owner choices: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, Lucide, Gemini server routes, and Supabase accounts. Use Radix-based shadcn source, native controls, shared Zod validation, private cloud persistence for accounts and local persistence for guests. CSS handles reduced-motion-aware transitions.

### Design Principles
1. One clear next action per state.
2. Keep financial and AI estimates explicit.
3. Preserve briefs and last successful plans on failure.
4. Use typography and whitespace before effects.
5. Keep all management actions available on mobile.
